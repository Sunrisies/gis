## 怎么用这个文件夹

1. **每天打开对应日期的文件夹**，读 `README.md`，照着做，不用再想今天干什么
2. 每个 `README.md` 的结构固定：**算法（如有）→ 今日任务 → 产出 → 参考资料 → 验收标准 → 今日记录**
3. 每天结束时把最下面的「今日记录」填掉
4. **周日多做一件事**：回答「拷问三问」并录音
5. 进度落后不要补，从当天继续（补进度是单休节奏崩掉的第一原因）

## 八、项目定义与仓库结构

一条**有因果关系的链**，不是并列的知识点：

```
公开数据 → GDAL/QGIS 处理 → Win 上切片为 3D Tiles → 本地瓦片服务
   → Cesium 加载 → Vue3 封装组件 + 标绘 → 10 万点海量渲染 + 轨迹回放
   → 采集性能基线 → Rust/WASM 优化 → 对比数据 → 部署上线 + 项目包装
```

| 环节 | 你补到的能力 |
|---|---|
| 数据处理 → 切片 → 服务 → 加载 | **切片、瓦片服务、离线/内网部署**（你现在完全没有的部分） |
| 3D Tiles + 海量点 | **3D Tiles 原理、LOD、Entity vs Primitive、海量点渲染** |
| 批量坐标转换 + 轨迹抽稀 | **Rust + WASM 的真实落点** |
| 图层管理 + 标绘 | **Vue3 Composition API 组件抽象** |
| 帧率 / 加载 / 内存 | **性能优化 + 可复现的量化数据** |
| 构建与部署 | **Vite 工程化、Cesium 静态资源坑** |

### 项目最终做成什么样（一个画面）

**一句话：** 一个能公网打开的「三维城市态势平台」——左边是三维城市（3D Tiles 建筑 / 地形），上面有一批移动目标点（10 万点级别），能回放历史轨迹，右下角有一块性能面板实时显示帧率、点数、加载耗时。

**别人打开链接会看到（这七条就是你的验收）：**

1. 页面**加载出来**（不白屏、不报错）→ 证明你会**切片 + 发布瓦片 + 部署**
2. 三维城市能**转动、缩放、飞到指定位置** → 证明你会 Cesium 相机与场景
3. 有**图层控制面板**，能勾选显隐不同图层 → 证明你会 **Vue3 组件抽象**
4. 能用鼠标**画点、线、面，画完能保存成 GeoJSON** → 证明你会**态势标绘**
5. 点「开始回放」，**10 万个点沿轨迹动起来不掉帧** → 证明你会**海量点渲染**
6. 右下角面板显示 **60fps / 10 万点 / 首屏 2.3s** → 证明你会**性能测量**
7. 他问「这 60fps 怎么来的」，你能打开 GitHub 上的对比数据表 → 证明你**真做过优化**

**关键：这个项目必须能被「点开」。** 二维码可随时分享，扫开就能看——这是这个项目最强的说服力。
