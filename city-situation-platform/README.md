# 三维城市态势平台

一个可公网访问的三维 GIS 演示平台，用于展示城市级空间数据的加载、交互与性能优化。

**在线 Demo**：（M6 部署后填）

---

## 打开链接会看到什么

1. 三维城市场景，可自由旋转、缩放、平移
2. 图层控制面板：切换底图、地形、建筑白模、点位数据
3. 标绘工具：在三维场景中绘制点 / 线 / 面，可编辑、可导出 GeoJSON
4. 10 万个点沿轨迹回放，保持流畅
5. 右下角性能面板：实时显示帧率、渲染点数、内存占用

---

## 技术栈

| 层 | 选型 |
|---|---|
| 前端框架 | Vue 3（Composition API） |
| 三维引擎 | Cesium |
| 二维引擎 | Mapbox GL JS（M4 对比用） |
| 数据处理 | GDAL / QGIS |
| 切片 | `fanvanzh/3dtiles`、`py3dtiles`（开源跨平台） |
| 性能优化 | Rust → WebAssembly |
| 部署 | 待定（M6） |

**为什么用 Cesium 而不是 Three.js**：Three.js 是通用渲染引擎，不带地理基准；
Cesium 内置 WGS84 椭球、瓦片 LOD 调度、地形影像对接，是「地理正确」的三维引擎。

## 数据来源

全部使用公开数据，来源与获取方式见 [`../公开数据下载清单.md`](../公开数据下载清单.md)：

| 数据 | 来源 | 坐标系 |
|---|---|---|
| 行政区划边界 | 阿里云 DataV | WGS84 / EPSG:4326 |
| 全球国界 / 海岸线 | Natural Earth | WGS84，带 `.prj` |
| 3D Tiles 样例 | CesiumGS 官方 | WGS84 |
| 激光点云 | PDAL 测试数据 | LAS 1.2 |
| 10 万点 / 轨迹 | 本项目脚本生成 | WGS84 |

```
city-situation-platform/
├── docs/                    踩坑文档（按主题记录，面试可直接投屏）
│   ├── 01-切片流程.md        原始数据 → 处理 → 切片 → 发布 → 加载

│   ├── 03-性能优化.md        优化前后对比数据
│   └── 04-WASM优化.md        Rust/WASM 实测与边界结论
├── src/
│   ├── components/           Vue 组件（MapContainer 等）
│   ├── composables/          组合式函数（图层、标绘）
│   └── wasm/                 WASM 产物与调用封装
├── rust/                     Rust 源码
├── perf/                     性能测试记录（CSV）
└── tiles/                    切片产物（不进版本库）
```

## 本地运行

```bash
# 数据服务（3D Tiles 必须走 HTTP，不能 file://）
cd ../data/raw && python3 -m http.server 8080

# 前端
npm install && npm run dev
```
