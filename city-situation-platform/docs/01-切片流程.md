# 切片流程：从原始数据到页面显示

> 状态：🟡 进行中（D8–D14 逐步填）
> 这份文档记录**完整链路**：原始数据 → 处理 → 切片 → 发布 → 加载

## 链路总览

```
原始数据                    处理                 切片                发布            加载
─────────                ──────              ──────            ──────         ──────
shp / GeoJSON    ──▶   ogr2ogr 重投影   ──▶  （矢量不切）  ──▶  nginx/CDN  ──▶  Cesium
GeoTIFF 影像     ──▶   gdalwarp 裁剪    ──▶  gdal2tiles   ──▶  HTTP 服务  ──▶  UrlTemplate
LAS 点云         ──▶   （坐标系转换）    ──▶  py3dtiles   ──▶  HTTP 服务  ──▶  Cesium3DTileset
OSGB 倾斜摄影    ──▶   （顶层节点合并）  ──▶  fanvanzh/3dtiles ──▶ HTTP  ──▶  Cesium3DTileset
```

## 环境

- 操作系统：macOS（Apple Silicon）
- 切片工具：`fanvanzh/3dtiles`、`py3dtiles`（开源、跨平台）
- 数据处理：GDAL / QGIS
