# 坐标系踩坑记录

> 状态：🟡 进行中（D4–D5 逐步填）

## 会遇到的坐标系

| 名称 | EPSG | 用途 | 坑 |
|---|---|---|---|
| WGS84 经纬度 | 4326 | GPS 原始输出、GeoJSON 规范 | GeoJSON **只能**是它 |
| CGCS2000 经纬度 | 4490 | 国内测绘法定基准 | 与 4326 差**厘米级**，工程常近似等同 |
| Web Mercator | 3857 | 所有 Web 瓦片地图 | 面积变形严重，但切片规整 |
| GCJ-02 | 无 | 高德 / 腾讯底图 | **加密偏移，不是标准投影** |
| BD-09 | 无 | 百度底图 | 在 GCJ-02 上二次偏移 |

## Cesium 的三种坐标表示

| 类型 | 含义 | 单位 |
|---|---|---|
| `Cartesian3` | ECEF 地心空间直角坐标 | 米 |
| `Cartographic` | 经纬高 | **弧度**（不是度！） |
| 屏幕坐标 | 像素 | px |

转换：
```js
// 经纬度 → ECEF
const p = Cesium.Cartesian3.fromDegrees(lon, lat, height)

// ECEF → 经纬度（注意 toDegrees）
const c = Cesium.Cartographic.fromCartesian(p)
const lon = Cesium.Math.toDegrees(c.longitude)
const lat = Cesium.Math.toDegrees(c.latitude)
```

## 已知坑清单

1. `Cartographic` 的经纬度是**弧度**，直接当度用会偏到南极
2. 3D Tiles 是 WGS84、底图是 GCJ-02 → **整体错位**
3. GeoJSON 规范规定坐标必须是 WGS84，**不能带投影**
4. `proj4js` **不做** GCJ-02 纠偏（它不是标准投影），要用 `gcoord`
