## 三、常用命令（复制即用）

### 起本地服务（**必须，不能 `file://`**）

```bash
cd data/raw
python3 -m http.server 8080
# 验证：浏览器打开 http://localhost:8080/china.json 应显示 JSON
```

### Cesium 加载样例瓦片

```js
const tileset = await Cesium.Cesium3DTileset.fromUrl(
  'http://localhost:8080/3d-tiles-samples/TilesetWithDiscreteLOD/tileset.json'
)
viewer.scene.primitives.add(tileset)
viewer.zoomTo(tileset)
```

### Cesium 加载 10 万个点

```js
const pts = await (await fetch('http://localhost:8080/points-100k.json')).json()
const collection = viewer.scene.primitives.add(new Cesium.PointPrimitiveCollection())
for (const [lon, lat, h] of pts) {
  collection.add({ position: Cesium.Cartesian3.fromDegrees(lon, lat, h) })
}
```

### ogr2ogr 转换（D2/D7）

```bash
cd data/raw
# shp → GeoJSON
ogr2ogr -f GeoJSON -lco ENCODING=UTF-8 out.geojson \
  natural_earth/ne_110m_admin_0_countries/ne_110m_admin_0_countries.shp

# 重投影到 CGCS2000（D4 要用）
ogr2ogr -f GeoJSON -t_srs EPSG:4490 out_4490.geojson \
  natural_earth/ne_110m_admin_0_countries/ne_110m_admin_0_countries.shp

# 查看坐标系
ogrinfo -so -al natural_earth/ne_110m_admin_0_countries/ne_110m_admin_0_countries.shp
```

### 重新生成合成数据（改点数时用）

```bash
node data/scripts/gen-data.js
```

**为什么用固定种子**：M3 要「同一份数据测 5 次」，固定种子保证每次生成结果完全一致，换机器也能复现。

## 四、这些数据为什么够用

| 面试可能问的 | 你手上的数据能怎么答 |
|---|---|
| 「你处理过什么坐标系的数据？」 | Natural Earth 的 `.prj` 是 WGS84，我转过 4490，对比过数值差异 |
| 「3D Tiles 的 LOD 怎么验证？」 | 我加载了官方 DiscreteLOD 样例，改 SSE 观察三级切换 |
| 「10 万点怎么优化？」 | 我有固定的 10 万点数据集，Entity 和 Primitive 各测 5 次取中位数 |
| 「点云数据你处理过吗？」 | 用 py3dtiles 把 LAS 切成 pnts，注意了坐标系与瓦片划分 |
| 「数据体积怎么优化？」 | 同一份行政区划，GeoJSON → TopoJSON 小了 XX% |

**关键点：数据是「可复现的」而不是「随便下的」**。你能说清每份数据的来源、坐标系、以及为什么选它——这才是面试要的。

## 六、注意：`data/raw/` 已加进 `.gitignore`？

**检查一下**。当前 `.gitignore` 里有：

```
data/raw/
data/tiles/
data/processed/
```

**这意味着数据不会被提交到 GitHub。** 这是**故意的**，理由：
- 36 MB 不算大，但 `data/tiles/`（切片产物）会有几十万个小文件
- 面试时对方 clone 仓库，数据可以按这份文档重新获取

**如果你希望数据一起进仓库**（比如想在线预览），把那三行从 `.gitignore` 删掉即可：

```bash
cd ~/Desktop/技术提升
# 编辑 .gitignore，删掉 data/raw/ 那行
git add data/raw && git commit -m "加入数据文件" && git push
```

**我的建议**：`data/raw/`（36 MB）可以提交，方便你换电脑直接用；
`data/tiles/`（切片产物）**绝对不要提交**，几千个小 b3dm 会让 Git 彻底卡死。
